# ☸️ Kubernetes Core Concepts

Fundamental abstractions in container orchestration.

## Core Primitives
- **Pod**: Smallest deployable unit containing one or more tightly coupled containers.
- **Deployment**: Declaratively manages Pod replicas, rollouts, and rollbacks.
- **Service**: Stable networking endpoint and load balancer for dynamic Pod IPs.
- **ConfigMap / Secret**: Decoupled configuration and credential injection into containers.
- **Ingress**: Manages external HTTP/HTTPS routing into internal cluster Services.
